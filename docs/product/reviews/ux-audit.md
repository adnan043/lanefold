## Delightful details worth adding

- Undo everything quick: the undo bar covers moves and archive; extend to lane archive, mark done, and message delete ("Message deleted. Undo", server delete after 8 s).
- Completion moment: moving a card into a lane named Done or ticking it animates the title strike-through (150 ms) and a soft accent flash on the card border, only under `prefers-reduced-motion: no-preference`.
- Quick-add parser in `CardComposer`: `Fix login @sam !high #tomorrow` sets assignee, priority and due, shown as chips under the textarea as you type.
- Inline title edit on `F2` or double-click on the card.
- WIP nudge: `lane.tsx:27` only reddens the count. Add an icon, "Over the limit by 2" in the pill's `title`, and a polite announcement when a drop pushes a lane over.
- Peek preview: hover or long-press 600 ms shows a popover with the description's first line and checklist progress.
- Presence on boards: avatar stack of viewers (the `rev` poll at `use-board-sync.ts:50` can carry a heartbeat) and "Sam moved this card" as `aria-live` text.
- Card to chat: a "Discuss" button on the card panel that opens board chat with the card link pre-filled (the product pitch in one click).
- Chat: `:tada:` shortcodes, "jump to first unread" divider using `markRead` seq, typing indicator through the `pulse` poll, drag a file into the composer once files land.
- Lane header meter (`lf-meter`) is `aria-hidden`; expose "To do, 4 of 6" in the lane's `aria-label`.
- Import from Trello offered in the empty boards state (About page already advertises it).
- My Day: drag from Inbox onto today; an end-of-day "3 things done" line.

## AGENTS.md UI-rule violations and near-violations

1. Buttons, "only the acted-on row shows pending": `archiveCard` (`boards/actions.ts`) has no in-flight guard; a double-click on the menu item fires two archives and the second rolls back with an error toast. Track in-flight ids.
2. Buttons, "disabled when it cannot act, visibly": `lane.tsx:79` collapse is `disabled={!canWrite}`; collapse is a personal view, not a write. Let viewers collapse locally (localStorage) instead of a dead control.
3. Fields, "every field has a visible label": the card composer (`composers.tsx:73`), lane-name input (`:169`) and chat composer (`composer.tsx:70`) use an `sr-only` label plus placeholder. Either keep a small visible caption or record the exception in `ui.md`. Two hidden-text classes coexist (`sr-only` in `app/app.css:7`, `visually-hidden` in `styles/app.css:32`): pick one.
4. Fields, "`aria-invalid` + `aria-describedby`": `composers.tsx:82-83` points `aria-describedby` at the hint only, never the error (the error `<p role="alert">` has no id); the lane composer (`:176-181`) has neither. Give the error an id and include it.
5. Never `style={}`: `card.tsx:~111` and `lane.tsx:~66` pass `style={{transform, transition}}` for dnd-kit. React applies it through the CSSOM so the CSP holds, but the rule says never: set it in a ref (`node.style.transform`, as lane colour already does) or note the exception in `ui.md`.
6. One-sided colour stripe: none in `app.css`, `chat.css`, `phase3.css`. `chat.css:436,473` `border-inline-start` is a neutral `--line` panel divider, not a state stripe. `.lf-lane[data-over]` is a full border (good).
7. Hex in screens: none in `src/app/**` CSS. Public side: `pricing.css:73` uses physical `margin-right: 8px` (breaks RTL) and a `\2713` pseudo-element with no text alternative; use `margin-inline-end` and an `aria-hidden` inline SVG. The page also hard-codes English outside `site.ts` ("Most popular", "Questions").
8. Destructive actions need confirmation: card archive from the menu has Undo, no confirm. Better UX, but record it as an explicit exception in `ui.md`. Lane and board archive confirm.
9. `window.confirm` / `alert`: none found.
10. Heading levels: lane names are `<h3>` (`lane.tsx:67`) with no `<h2>` above them on the board. Use `<h2>`. `lf-board` has an `aria-label` on a plain `div` (`board-screen.tsx:194`): add `role="region"`.
11. ARIA: `role="combobox"` on `<textarea>` (`composer.tsx:79`) is invalid. The mobile drawer closes on Escape but focus is not moved in, trapped or returned to the menu button (`shell.tsx:122-126`).
12. Never show another person's email: none of the audited screens render an email (palette people show name and role). Good.

## Already good (keep)

Optimistic, rollback-safe board moves with fractional positions; keyboard-draggable cards with localised announcements; the undo bar; focus return in composers; `LoadingBlock` / `EmptyState` / `ErrorNote` on every list; hover-only controls revealed on `:focus-within` and always on `(hover: none)`; logical properties throughout the app CSS; dark tokens defined three times with a contrast test; `noValidate` forms with `useForm`; stale-bundle recovery in `RouteError`.
