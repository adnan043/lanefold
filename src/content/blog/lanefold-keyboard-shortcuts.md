Lanefold is built to be used without reaching for the mouse. Press `?` anywhere in the app to see this list in a dialog.

## General

| Keys | What it does |
| --- | --- |
| `?` | Open or close the shortcuts help |
| `/` | Open the command palette |
| `Ctrl` + `K` | Open the command palette (`Cmd` + `K` on a Mac) |

## Go to a screen

Press `g`, then a second key within about a second and a half:

| Keys | Where it goes |
| --- | --- |
| `g` then `b` | Boards |
| `g` then `m` | My Day |
| `g` then `i` | Inbox |
| `g` then `c` | Chat |

## Create

| Keys | What it does |
| --- | --- |
| `n` | Press the screen's first "add" button: a card on a board, a board on the boards list |

## When shortcuts do not fire

So they never get in your way, single-key shortcuts are ignored when:

- you are typing in a field, a text area or any editable text;
- a dialog or menu is open (except `?`, which toggles the help);
- `Ctrl`, `Cmd` or `Alt` is held, so browser and system shortcuts keep working.

## Tips

- If you are not sure where something is, open the palette with `/` and type.
- `g` on its own does nothing: if you press it by mistake, wait a moment or press another key.
- On a screen with nothing to add, `n` does nothing, and that is expected.

More shortcuts are planned. This page lists only what works today.
